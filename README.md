# Micro ML Projects

A collection of small machine learning projects covering **classification, regression, data preprocessing, feature engineering, model evaluation, and hyperparameter tuning** using Python and Scikit-learn.

These projects were built to practice end-to-end machine learning workflows and apply different supervised learning techniques to practical datasets.

## Projects

| Project | Type | Key Concepts |
|---|---|---|
| **Employee Turnover Prediction** | Classification | Logistic Regression, L1/L2 Regularization, Model Evaluation |
| **House Price Prediction** | Regression | Linear Regression, Data Cleaning, Categorical Encoding, Regression Metrics |
| **ShopSmart – Purchase Prediction** | Classification | Decision Trees, Imbalanced Classification, F1-score, GridSearchCV, Cost-Complexity Pruning |

## Purpose

This repository serves as a practical collection of **hands-on machine learning exercises** designed to strengthen understanding of the complete supervised learning workflow — from data preparation and exploratory analysis to model training, evaluation, regularization, hyperparameter tuning, and model optimization.

The projects emphasize **practical implementation and experimentation** with different machine learning techniques rather than focusing solely on model training.
